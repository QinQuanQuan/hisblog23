# hisblog23 — 博客归档站点

Quanquan's Blog 的静态归档。此仓库由 GitHub Pages 托管，通过子域名访问：

- **线上地址**：<https://hisblog23.qinquanquan.com>
- **仓库 Pages 站点**：<https://qjhquanquan.github.io/hisblog23>（仅仓库预览，根路径资源在其下不生效，请以上述自定义域名为准）

## 说明

- 内容为 Hexo 7.0.0 生成的静态站点输出，原存放于 `QjhQuanQuan/QjhQuanQuan.github.io`（用户站点），于 2026-09 整体迁移至此。
- **仅提供查看，不再更新内容**。
- `CNAME` 内容为 `hisblog23.qinquanquan.com`；`.nojekyll` 用于禁用 Jekyll 处理，保证静态文件原样发布。
- 仓库内资源全部使用根绝对路径（`/css/...`、`/2023/...`），依赖“域名根目录”部署方式，请勿以子路径方式部署。

## 目录速览

| 路径 | 内容 |
| --- | --- |
| `index.html` | 首页 |
| `archives/`、`categories/`、`tags/` | 文章归档 / 分类 / 标签索引 |
| `2023/`、`2024/` | 文章正文（按 Hexo permalink 结构：年/月/日/标题） |
| `css/` `js/` `fonts/` | 主题资源 |
| `pic/` `image/` | 文章配图与头像 |
